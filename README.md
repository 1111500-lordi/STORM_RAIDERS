## História do Jogo

Storm Raiders é um jogo de sobrevivência com temática de piratas dos céus, em que o jogador assume o controle de um navio voador em meio a um lugar muito mais vasto e perigoso do que o próprio oceano: o céu. Durante a partida, canhões inimigos disparam continuamente, exigindo reflexos rápidos para desviar dos projéteis e permanecer vivo.
Quanto mais tempo o jogador sobreviver, maior será sua pontuação. O objetivo é alcançar a melhor marca possível e conquistar uma posição no ranking dos maiores capitães dos céus.

## Como Executar

1. Instale as dependências:
   pip install pygame

2. Execute:
   python main.py

## Executável

O executável do jogo encontra-se na pasta build gerada pelo comando:

python setup.py build
